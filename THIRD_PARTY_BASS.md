# BASS libraries

This project includes 64-bit Windows DLLs from Un4seen Developments:

- `bass.dll`
- `bass_aac.dll`
- `bassalac.dll`
- `bassape.dll`
- `bassdsd.dll`
- `bassflac.dll`
- `basshls.dll`
- `bassmidi.dll`
- `bassopus.dll`
- `basswebm.dll`
- `basswma.dll`
- `basswv.dll`

Source: https://www.un4seen.com/bass.html
